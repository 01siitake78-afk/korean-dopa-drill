## 2. 対象範囲

算数の5領域（A 数と計算、B 図形、C 測定、C 変化と関係、D データの活用）のうち、テンキーで数値を答えられる計算を対象とする。

- 対象：A 数と計算の四則計算・筆算・小数・分数・計算のきまり・概数・約数と倍数、C 変化と関係のうち計算で答えられる割合（百分率）と比、6年の文字を用いた式（□やxに当てはまる数）。
- 対象外：図形、測定（長さ・かさ・時刻等）、グラフ・データ、文章題、数の読み書き（漢数字・大きな数の位取り表記）。

対象外の領域は、数値入力では学習内容を正しく扱えないため除外する。文章題は後続候補として保持する。

## 3. 学年ごとの計算の内容（告示本文の要約）

### 第1学年

- 1位数と1位数との加法及びその逆の減法（くり上がり・くり下がりを含む）。
- 簡単な場合の2位数などの加法及び減法（例：23＋4、30＋40）。
- 3つの数の加法・減法（3口の計算）。数の合成・分解（10のまとまり）。

### 第2学年

- 2位数の加法及び減法の筆算。簡単な場合の3位数などの加法及び減法。
- 乗法九九。簡単な場合の2位数と1位数の乗法（例：20×3）。
- 1/2、1/4など簡単な分数（もとの数の何分の一）。

### 第3学年

- 3位数や4位数の加法及び減法の筆算。
- 2位数や3位数に1位数や2位数をかける乗法の筆算。
- 除数と商が1位数の除法、余りのある除法。簡単な場合の除数が1位数で商が2位数の除法（例：60÷3）。
- 小数（1/10の位）の加法及び減法。簡単な場合の同分母分数の加法及び減法。

### 第4学年

- 除数が1位数や2位数で被除数が2位数や3位数の除法の筆算。被除数＝除数×商＋余り。
- 概数と四捨五入。四則の混合した式と（ ）の計算、計算のきまり。
- 小数の加法及び減法、乗数や除数が整数である小数の乗法及び除法。
- 同分母分数の加法及び減法（帯分数・仮分数を含む）。

### 第5学年

- 乗数や除数が小数である小数の乗法及び除法。
- 約数・倍数、最大公約数・最小公倍数。約分・通分。異分母分数の加法及び減法。
- 乗数や除数が整数である分数の乗法及び除法。
- 百分率（C 変化と関係）。

### 第6学年

- 乗数や除数が分数である分数の乗法及び除法。小数と分数の混じった計算。
- 比と比の値、等しい比（C 変化と関係）。
- 文字を用いた式（xに当てはまる数）。

## 4. スキルへの分解

1つのスキルは「1種類の手順が身に付いたかを判定できる単位」とする。例として、2けたのたし算の筆算は「くり上がりなし」と「くり上がりあり」を別のスキルに分ける。

各スキルは次の項目を持つ。

| 項目 | 内容 |
| --- | --- |
| id | 英数字の識別子（例：`g2-vadd2-c`） |
| 名前 | 画面に出す短い名前（ひらがな多め） |
| 学年 | 学習指導要領上の標準学年 |
| 系統（レーン） | ツリー画面の列。たしひき／かけわり／小数分数／そのほか |
| 前提 | 解放に必要なスキル（すべて習熟で解放） |
| 問題の型 | 出題エンジン（id020）の生成器名と条件 |

スキルの一覧と前提関係は `app/js/skills.js` を正とする。以下は系統ごとの流れの要約である。

### たしひき（加法・減法）

10のまとまり → 1けたのたし算（くり上がりなし）→ ひき算（くり下がりなし）→ くり上がり → くり下がり → 3つの数 → 2けた＋1けた（簡単）→ 2けたの筆算（くり上がりなし・あり、くり下がりなし・あり）→ 3けたの簡単な筆算 → 3けたの筆算 → 4けたの筆算（0をまたぐくり下がりを含む）。

### かけわり（乗法・除法）

九九（5・2の段 → 3・4の段 → 6・7の段 → 8・9・1の段 → まぜこぜ）→ 何十×1けた → 2けた×1けたの筆算 → 3けた×1けた → 2けた×2けた → 3けた×2けた。
九九 → わり算（九九1回）→ あまりのあるわり算 → 何十÷1けた（簡単）→ 2けた÷1けたの筆算 → 3けた÷1けた → 2けた÷2けた → 3けた÷2けた。

### 小数分数

簡単な分数（もとの数の1/2、1/4）→ 小数第1位のたし算・ひき算 → 同分母分数（和が1以下）→ 小数第2位までのたし算・ひき算 → 小数×整数 → 小数÷整数 → 同分母分数（帯分数・仮分数）→ 小数×小数 → 小数÷小数 → 約分 → 異分母分数のたし算・ひき算 → 分数×整数・分数÷整数 → 分数×分数 → 分数÷分数 → 小数と分数のまじった計算。

### そのほか

計算のきまり（（ ）、×÷を先に）、概数（四捨五入）、最大公約数・最小公倍数、百分率、比（等しい比）、文字を用いた式（x）。

## 5. 習熟と解放の規則（仮案）

- 習熟：そのスキルの直近6問のうち5問以上を初回正解（途中入力を含め誤答なし）。
- 解放：前提スキルがすべて習熟になると解放する。前提がないスキルは最初から解放済み。
- 最初の実力判定：じぶんレベルの初回に、各系統の易しいスキルから順に数問ずつ出題する。初回正解が続いたスキルは習熟扱いとして先へ進む。
- 学年別モードでは、その学年のスキルだけから出題し、解放状態は問わない。

数値はエージェントの仮案である。試作と人間レビューで調整する。

## 6. 入力の方式

- 横書きの式（例：`7 ＋ 5 ＝ □`）は、答えの数字を左から入力する。
- 筆算の加減乗は一の位から、わり算は商の上の位から入力する（従来の筆算と同じ）。
- 余りのあるわり算は「商 → 余り」の順に入力する。
- 分数の答えは「分母 → 分子」の順に入力する（学校で分母から書く指導に合わせる）。帯分数は「整数部分 → 分母 → 分子」とする。答えは既約分数で判定する。
- 小数点は自動で表示し、数字だけを入力する。
