# 歌詞の追加

1. 曲ごとの JSON をこのフォルダーに追加します。
2. `app/js/lyrics.js` の `SONGS` に id と file を追加します。
3. JSON は `id`, `title`, `artist`, `lines` を持ちます。各行は `id`, `korean`, `japanese`, `tokens` で構成します。
4. `tokens` は単語または自然な文節の配列です。半角スペースで連結した値を `korean` と一致させてください。

Wonderland（30問）、HALAZIA（36問）、BAD（10問）はユーザー提供の対訳を使用。英語のみの行、1枚だけになる行、繰り返しの同一行は出題から除外しています。混在する英語は元データを維持しています。BAD の訳文に混ざっていた「歌詞を検索する」「語学教材を探す」は除去しています。

追加したカードには `app/js/lyrics-help.js` でカタカナの読み方と文脈に合わせた日本語の意味も登録してください。カタカナは発音の目安で、対訳は提供ファイルの表記を維持しています。
